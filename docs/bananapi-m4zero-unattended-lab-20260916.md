# 0845 免反覆拔卡實驗環境

## 目標與本輪決策

使用者要求不再交付只有 SRAM 冒煙測試的半套流程：在這次卡片仍接主機時，把日後可由 UART 載入更新器、更新實驗程式及系統的基礎完整做好，再交回插入 `0845`。板型、串口與具名電源沿用本工作已核對的配置。

本次擴充以日常軟體實驗免拔卡為目標，不承諾任意程式破壞固定救援區、SD 失效或實體線路故障後仍可自動救回。固定 SPL1 不納入日常更新；硬體未驗證前不宣告整套已完成。

## 實作原則

1. 固定入口只負責無 DDR 的 UART、受限封包驗證與交接。新增更新器及開機橋接的明確負載種類，不冒充 DDR 或 smoke；現有 ABI 1／2 不暗中改義。
2. 更新器本身可從 UART 載入 SRAM，因此卡上更新器副本損壞不應再次要求拔卡。使用 U-Boot 既有 MMC PIO 與傳輸實作，不自行重寫 SD 協定。
3. 更新必須先核對卡片與布局，只更新明確指定的可替換範圍；固定入口、分割表、安全副本不在日常寫入範圍。傳輸及媒體等待有界，寫後核對摘要，失敗不得宣告提交。
4. 實驗程式一次性執行。每次受控重啟先回固定入口，再由主機明確選擇已知安全或新的實驗負載，避免壞版本持續自動開機。
5. 開機橋接明確處理 SRAM 覆寫順序、原 SPL 入口及配套 FIT 的載入位置；不能把舊 SPL 放到不同地址直接跳轉。
6. 系統更新與小型 SRAM 程式分層：UART 保留為救援及小程式傳輸，完整映像優先走可驗證的 Linux 網路路徑。不能把每 GiB 約一天的 115200 UART 傳輸說成快速系統更新。
7. 本輪保留原系統與現有分割區，先用不重疊的開機保留空間配置小型槽；多系統可替換儲存須另有明確機器布局，不能把既有「槽 1」位址直接當可寫空白區。

## 固定配置

第三版使用明確的 `CONFIG_BPI_SRAM_LAB_V3`，不改變舊版卡片的槽位定義。舊版槽距為 1 MiB，槽 1 會落在原系統起點，禁止以舊布局進行日常寫入。

| 區域 | 起始磁區 | 長度 | 用途 |
| --- | ---: | ---: | --- |
| SPL1 | 16 | 40 KiB | 固定無 DDR 救援入口，日常更新器不可寫 |
| 配套 FIT | 2048 | 保留 1 MiB | 正常 A1 配套 TF-A、U-Boot、DTB；原 FIT 在磁區 96 保留 |
| 槽 0 | 6144 | 128 KiB | 保留既有 smoke，日常更新器不可寫 |
| 槽 1 | 6400 | 128 KiB | 固定更新器副本，日常更新器不可寫 |
| 槽 2 | 6656 | 128 KiB | 更新器候選，只接受 `kind=3` |
| 槽 3 | 6912 | 128 KiB | 開機或診斷候選，只接受 `kind=4` |
| 槽 4 | 7168 | 128 KiB | 第二個開機或診斷候選，只接受 `kind=4` |
| 原分割區 | 8192 | 保持原值 | 不重切、不縮小、不由 SRAM 小型更新器寫入 |

固定入口 `abi=3` 可載入第一版 smoke、第二版 DDR 契約及第三版更新／開機封包。此處允許 DDR 契約不代表既有 DDR 負載已取消其 PMIC／幾何配置守門。

更新器仍從 SRAM 執行且不初始化 DDR；先回報 CID、容量與 MBR 布局，主機核對後才傳送寫入命令。目標槽標頭先清零，內容回讀及摘要通過後才提交有效標頭，再次完整回讀。若最後回讀失敗，`committed=0` 表示「未取得提交成功證據」，不保證媒體完全未寫入；主機不得執行該候選。
