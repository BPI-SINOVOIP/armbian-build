# 停用平行快取清理紀錄

日期：2026-09-06

## 目的

全矩陣增量建置進行至 235／444 個映像時，可用空間降至 214.6 GiB。為避免候選發布在完成前碰到 40 GiB 安全門檻，本次只回收已停用平行工作樹的可重建快取，不刪除來源、映像、日誌、狀態、正式發布或目前建置所使用的快取。

## 清理範圍

| 路徑 | 清理前大小 | 性質 |
| --- | ---: | --- |
| `/media/pi/SMCI/armbian/bpi-v26.2.1-bananapi-parallel2/cache` | 約 187 GiB | 已停用工作樹的可重建 Armbian 快取 |
| `/media/pi/SMCI/armbian/bpi-v26.2.1-bananapi-parallel3/cache` | 約 177 GiB | 已停用工作樹的可重建 Armbian 快取 |

## 刪除前守門

1. 兩個路徑均為同一檔案系統上的實體目錄，不是符號連結。
2. 執行中程序的命令列、工作目錄與開啟檔案不得位於上述路徑。
3. 執行中容器的掛載來源不得位於上述路徑。
4. 目前增量服務只可使用 `/media/pi/SMCI/armbian/bpi-v26.2.1-bananapi-parallel/cache`。
5. 刪除命令必須限制於上述兩個精確路徑並禁止跨越檔案系統。

## 保留內容

- `bpi-v26.2.1-bananapi-parallel2` 與 `bpi-v26.2.1-bananapi-parallel3` 的 Git 工作樹。
- 兩個工作樹的 `output`、建置日誌與未納入快取的證據。
