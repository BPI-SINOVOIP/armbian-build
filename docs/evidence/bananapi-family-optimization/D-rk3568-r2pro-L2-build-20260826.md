# Banana Pi R2 Pro current 候選映像 L2 建置證據

日期：2026-08-27

## 結論

`bananapir2pro` 已由乾淨來源完整建置 Debian Trixie current minimal CLI，並通過 RK3568 專用 L2 唯讀守門。候選映像的固定來源、IMG／XZ 同一性、GPT、U-Boot 啟動載荷、RKBin、R2 Pro DTB、SD／eMMC、雙乙太網路、MT7531 交換器、SATA、雙 PCIe、USB host、顯示、GPU、媒體核心設定及標準開發工具均符合本次受控政策。

此結果不代表實體板已完成 UART、冷啟動、SD／eMMC、五埠交換器、SATA、PCIe、USB、顯示、GPU、媒體解碼或排針驗證；取得實機證據前維持 L2。板上 USB 控制器目前只建立 host 證據，不宣稱 OTG 或 gadget 功能。

## L2 守門範圍

1. 檢查候選矩陣、中繼資料、來源提交、來源樹、建置參數及建置／驗證政策雜湊一致。
2. 驗證固定 Linux、U-Boot、RKBin 與 Armbian firmware 提交，並保存三個 RK3568 啟動二進位檔的 SHA-256。
3. 以唯讀 loop 與 `mount -o ro,noload` 檢查映像，不執行映像內程式。
4. 檢查 GPT 第一分割區由 sector 32768 開始、名稱為 `rootfs`，並驗證 extlinux 指向 `rockchip/rk3568-bpi-r2-pro.dtb`。
5. 檢查 DTB SHA-256 `fd8c3afda2c21555989e44b9d552a2b5d1e1aedce3469c8d4c486caa6c4a2ea2`、model、compatible、SD 4-bit、eMMC 8-bit、雙乙太網路與 MT7531 的 WAN／LAN0 至 LAN3／CPU ports。
6. 檢查 SATA、雙 PCIe、USB host、HDMI、VOP、GPU、RGA 與三個媒體解碼／編碼節點；不把 DT 節點存在解讀為實機功能通過。
7. 檢查核心的 DSA、MT7530、Rockchip GMAC、AHCI、PCIe、MMC、DRM、Panfrost、Hantro、RGA、GPIO、I2C、SPI 與硬體亂數等必要設定。
8. 檢查網路、儲存、PCIe、USB、顯示、媒體與標準 I/O 驗證工具已安裝。

## L3 實機門檻

- 執行至少 30 次完整斷電冷啟，保存 UART 全程日誌及失敗率。
- 分別驗證 SD 與 eMMC 開機、安裝、交互啟動順序及斷電檔案系統一致性。
- 驗證兩個 GMAC、MT7531 的 WAN／LAN0 至 LAN3、VLAN、橋接、轉送效能與長時間負載。
- 驗證 SATA、兩個 PCIe、所有 USB host 埠、HDMI、GPU、RGA 與媒體解碼；記錄實際頻寬、溫度及錯誤。
- 驗證 GPIO、I2C、SPI、UART 與板卡實際引出的其餘介面。
