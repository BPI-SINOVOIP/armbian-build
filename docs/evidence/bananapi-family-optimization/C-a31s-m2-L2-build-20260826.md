日期：2026-08-26

## 結論

`bananapim2` 已由乾淨來源完整建置 Debian Trixie current minimal CLI，並通過 A31s 專用 L2 唯讀守門。此結果證明候選映像的固定來源、IMG／XZ 同一性、板級 U-Boot 載荷、A31s M2 DTB、AP6210 韌體、核心功能與標準開發工具符合本次受控政策。

此結果不代表實體板已完成 UART、SD 開機、DRAM、網路、Wi-Fi、USB、IR 或排針驗證；取得實機證據前維持 L2。主線 DTB 沒有足夠設定可宣稱顯示、音訊、eMMC、Bluetooth、OTG、USB gadget、GPU 或 VPU 已支援。

## L2 守門範圍

1. 檢查候選矩陣、中繼資料、來源提交、來源樹、建置參數及驗證設定雜湊一致。
2. 驗證固定 Linux、U-Boot 與 Armbian firmware 提交，以及 U-Boot 套件與映像載荷位元組一致。
3. 以唯讀 loop 與 `mount -o ro,noload` 檢查映像，不執行映像內程式。
4. 檢查核心、initrd、`overlay_prefix=sun6i-a31s` 與 `allwinner/sun6i-a31s-sinovoip-bpi-m2.dtb` 的 model、compatible 及檔名身分。
5. 檢查 SD 與 SDIO 為 4-bit，並檢查 SDIO Wi-Fi、Gigabit Ethernet、USB host、IR、UART、PMIC 與 USB PHY 設定。
6. 檢查 BCM43362 韌體與 NVRAM 雜湊，以及 Wi-Fi、Crypto、GPIO、I2C、SPI、IR、Ethernet 與 USB host 核心設定。
7. 檢查 `rfkill`、`iw`、`ethtool`、`usbutils`、`gpiod`、`i2c-tools`、`python3-libgpiod`、`python3-spidev` 與 `v4l-utils` 已安裝。

核心設定、模組、DT 節點、韌體或工具存在只證明軟體已封裝，不等同相關硬體路徑可用。上游 U-Boot 的 432 MHz DRAM 設定只代表可重現基線，不代表任一記憶體批次已通過壓力測試。

## L3 實機門檻

- 執行至少 30 次完整斷電冷啟，保存 UART 全程日誌及失敗率。
- 驗證不同記憶體與 SD 批次在 432 MHz DRAM 設定下的冷啟動、重啟、長時間壓力及溫度邊界。
- 驗證 SD、Gigabit Ethernet、Wi-Fi、USB host、IR 與斷線重連。
- 驗證 GPIO、I2C、SPI、UART 與欲發布介面的實體迴路、腳位衝突及電壓域。
- 後續若補齊顯示、音訊、Bluetooth 或加速裝置樹，必須另建映像並取得獨立證據，不能回溯套用本次 L2 結果。
