# Banana Pi BPI-6204 legacy 候選映像 L2 建置證據

更新日期：2026-08-27

## 結論

`bananapi6204` 已由乾淨來源完整建置 Debian Trixie legacy minimal CLI，並通過 R40 6204 專用 L2 唯讀守門。候選映像的固定來源、IMG／XZ 同一性、MS-DOS 分割表、U-Boot 載荷、完整板級 DTB、保守 eMMC 設定、SATA、GMAC、CAN、雙 RTC、五組 UART、USB、Lima、Cedrus 與工控 I/O 工具均符合本次受控政策。

此結果不代表實體板已完成 UART、冷啟動、SD／eMMC、SATA、網路、CAN、RTC、USB、顯示、音訊、GPU、VPU 或排針驗證；取得實機證據前維持 L2。

## 裝置樹修正

既有 6204 DTS 補丁宣告 341 行、實際來源有 376 行，導致核心只取得截斷內容。修正後的 378 行 DTS 補回 UART0／3／4／5／7、USB PHY 尾段，以及 SPI1 的 PI pinmux 與 CS1 pinmux。

映像內 `sun8i-r40-bpi-6204.dtb` SHA-256 為 `266250249d06a6d217b20d13663b33af6b831d69b9dcd77247d1ea58e5554e11`。守門逐項確認：

- SD 4-bit、SDIO 4-bit 與 eMMC 8-bit；eMMC 維持 25 MHz，且沒有 1.8 V 高速宣告。
- SATA、GMAC、HDMI、USB host、MCP2515 CAN、EEPROM、DS1340 與 ISL1208。
- UART0／3／4／5／7、GPIO、PWM、Lima、Cedrus 與 Crypto Engine。
- SPI1 pinctrl 與 CS1 pinctrl 已實際寫入編譯後 DTB。

## L2 守門結果

1. 固定 Linux、U-Boot 與 Armbian firmware 完整提交碼。
2. 驗證 IMG、XZ、檔名、中繼資料與板卡身分一致。
3. 驗證分割表、第一分割區起點、U-Boot 最終設定及實際寫入載荷。
4. 驗證 boot script、`armbianEnv.txt`、核心版本、DTB 精確雜湊及必要核心設定。
5. 驗證 `can-utils`、`ethtool`、`iperf3`、`smartmontools`、`hdparm`、`gpiod`、I2C、SPI、V4L2、音訊、無線與感測工具已安裝。

唯讀驗證結果為 L2 完成，U-Boot 載荷證據清單 SHA-256 為 `c01665ab4abec43f2d6d48ca23aa558d34cbdabd8efafc27c8dc698b4e1c7d92`。

## L3 實機門檻

- 以 UART 記錄多次冷啟動、重新啟動與關機，確認 SPL DRAM、MMC 與核心啟動沒有間歇性錯誤。
- 分別驗證 SD 與不同廠牌 eMMC 的讀寫、斷電恢復及長時間壓力。
- 驗證 SATA、Gigabit Ethernet、CAN loopback／外接節點、雙 RTC 與五組 UART。
- 驗證 USB host、HDMI、音訊、Lima OpenGL ES、Cedrus V4L2 解碼及工控排針。
- 執行 CPU、記憶體、儲存與網路混合壓力，保存溫度、節流、錯誤計數與測試時間。
