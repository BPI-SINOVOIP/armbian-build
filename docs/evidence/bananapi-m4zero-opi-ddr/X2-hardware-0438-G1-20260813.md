# X2 在 0438 板的標準啟動 G1 證據

## 結論

Rayson `0438` 使用 X2 792 MHz 標準映像完成一次完全斷電冷啟動。SPL 的四個
雙 Rank geometry 階段都一次通過，最終識別 4,096 MiB、x32、2 Rank、
16 Rows、10 Columns；TF-A、U-Boot、核心、initramfs、rootfs 與使用者空間
全部通過。

systemd 狀態為 `running`，失敗服務為零，`wlan0` 已建立。另完成 180 秒、
3.0 GiB 記憶體與 4 個 CPU worker 的冒煙測試，結束碼為 `0`，沒有 OOM、
page fault、panic、Oops、EDAC 或資料毀損訊息。

本結果通過 G1 並計入 G2 `1/10`。短壓力結果不能取代完整 G3 或兩小時 G4。

M4ZDDR1_PROFILE1 dx_odt=07070707 dx_dri=0e0e0e0e ca_dri=00000d0d odt_en=aaaaeeee

四個 geometry 階段均一次通過。U-Boot 完成 initrd checksum、DTB、overlay
與核心載入。Linux `6.18.32-current-sunxi64` 回報
`3907336K/4194304K` 可用記憶體；rootfs 為 `/dev/mmcblk0p1` ext4 讀寫掛載，
UUID 為 `79b65bfb-8d06-41a2-950a-8aa06b351317`。

| 檢查 | 結果 |
| --- | --- |
| systemd | `running` |
| 失敗服務 | `0` |

| initramfs | 正常解包並掛載 rootfs |
| MMC | SD 與 29.1 GiB eMMC 均正常枚舉 |
| 錯誤關鍵字 | 只有 watchdog `timeout=16 sec` 正常設定 |

```bash
stress --vm 1 --vm-bytes 3000M --vm-keep --cpu 4 --timeout 180s
```

```text
stress: info: successful run completed in 180s
STRESS_RC=0
```

測試後可用記憶體約 3.7 GiB，swap 使用量為零；核心日誌未命中 OOM、
page fault、panic、Oops、資料毀損、Data Abort 或 EDAC 關鍵字。這是冒煙測試，
尚未涵蓋完整 pattern、溫度角落或記憶體與 MMC 長時間並行。

板上時鐘尚未透過網路校時，UART 中的系統日期為 2026-05-21；本證據以主機
建立目錄與擷取時間 2026-08-13 為準。
