# M4ZLAB2 在 0845 板的 792 MHz 參數收斂證據

## 結論

板號 `450600845` 使用固定 `M4ZLAB2` SPL 完成 305 組執行期 DDR 實驗。
原 X2 792 MHz 參數在 M2 重現資料位元錯誤；改用 1116 原廠動態訓練輸出的
`tpr11=0x25252523` 與 `tpr12=0x110f0f10` 後，候選中心在小窗口 M2
完成 `20/20`，並在 64 MiB、五輪 pattern 的強測完成 `3/3`，沒有錯誤。

```text
0845 geometry：4,096 MiB、2 Rank、x32、16 Rows、10 Columns
原 X2 792 MHz M2：4/5 通過，1 次資料位元錯誤
0845 候選 792 MHz M2 小窗口：20/20 通過
0845 候選 792 MHz M2 64 MiB 強測：3/3 通過
候選 TPR6 實測通過窗：0x30..0x42
實測失敗邊界：0x2e、0x44
冷開機、Linux 全容量壓力與量產驗收：尚未通過
```

## 原 X2 反證

原 X2 中心參數如下：

```text
tpr6=0x3a808080
tpr11=0x24242422
tpr12=0x110f1111
```

0845 的五次 M2 基準為 `4/5`。失敗記錄不是單純逾時，而是明確資料錯誤：

```text
test=words
addr=0x000000013fb3c0a0
expected=0x92e7422af4094a9d
actual=0x92e7422af4094a9f
```

因此先前 X2 在 0845 的 PID 1 問題不能再只歸因於 rootfs；至少已證明原 X2
DDR lane 參數在這片板的 792 MHz margin 不足。

## 參數配對收斂

只改 `tpr12`、但保留 X2 `tpr11` 時，`tpr6=0x3a` 為 `3/5`。保留 X2
`tpr12`、改用原廠 `tpr11` 時為 `5/5`；兩者一起改為原廠輸出後為 `5/5`。
結果顯示 `tpr11` 是主要差異，但兩個 packed lane 參數必須成對驗證，不能
只根據單一短測拆開採用。

最後候選如下：

```text
clk=792
dx_odt=0x07070707 dx_dri=0x0e0e0e0e ca_dri=0x00000d0d
odt_en=0xaaaaeeee
tpr6=0x3a808080 tpr10=0x402f6663
tpr11=0x25252523 tpr12=0x110f0f10
```

機器可讀設定位於：

```text
tools/bpi-m4zero-ddr-lab-profile-0845-candidate-792.json
```

## TPR6 邊界

在上述原廠 lane 配對下，每點執行三次 M2：

| `tpr6[31:24]` | 結果 |
| --- | ---: |
| `0x20..0x2e` | 每點 0/3 |
| `0x30..0x36` | 每點 3/3 |
| `0x37` | 20/20；另有 64 MiB 強測 3/3 |
| `0x38` | 3/3 |
| `0x3a` | 20/20；另有 64 MiB 強測 3/3 |
| `0x3c..0x42` | 每點 3/3 |
| `0x44..0x46` | 每點 0/3 |

0845 的已觀察零失敗區間為 `0x30..0x42`，兩端都有完整失敗邊界。`0x3a`
接近區間中心，且等於 1116 原廠動態輸出，所以不另取 0845 單板特調值。

## 頻率與測試層級

M0 在 480 至 792 MHz 的十個點共 `50/50`，M1 在 672 至 792 MHz 的七個點
共 `35/35`。只有 M2 抓到原 X2 參數的間歇資料錯誤，證明 M0、M1 適合粗掃，
不能作 792 MHz 最終放行依據。原 X2 lane 下的 M2 頻率掃描為 720 至
780 MHz 各 `5/5`，792 MHz 為 `4/5`；780 MHz 可作暫時降頻參考，但本輪
目標仍是收斂可用的 792 MHz 參數。

## 限制與下一個 Gate

1. 這是單片 0845、同次上電後的熱重設實驗，不是量產共同設定。
2. M2 分散窗口與 Rank 邊界測試不能取代 Linux 全容量記憶體壓力。
3. 新 lane 配對來自 1116 原廠動態結果，但尚未在 0438、2 GiB 單 Rank 與
   舊 V2 弱板重新執行相同強測。
4. 建立標準 U-Boot 工程映像後，0845 必須先做完整斷電冷啟動與 Linux 壓力；
   再由多板共同窗口決定是否取代 X2。
