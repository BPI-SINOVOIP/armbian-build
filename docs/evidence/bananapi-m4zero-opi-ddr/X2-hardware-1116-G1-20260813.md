# X2 在 1116 板的標準啟動 G1 證據

## 結論

`1116` 使用 X2 792 MHz 標準映像完成一次完全斷電冷啟動，從 SPL、TF-A、
U-Boot proper、核心、initramfs、rootfs 到使用者空間全部通過。systemd 狀態
為 `running`，失敗服務為零；先前 O1 曾出現的 initramfs 解包錯誤沒有重現。

本結果通過 G1，並計入 G2 的第一次冷啟動 `1/10`。它尚未通過 G2、G3、
G4，也不能外推到三星 DDR 樣本或量產批次。

## 固定輸入與 SD 卡寫入

| 項目 | 值 |
| --- | --- |
| 完整映像 | `Armbian-unofficial_26.05.0-trunk_Bananapim4zero_jammy_current_6.18.32_x2-cross-board-792mhz.img` |
| 映像大小 | `2034237440` 位元組 |
| 映像 SHA-256 | `fb665992d6a5becfe2694cade5f2e1367f0eeb18582fdcda8e8d3d446042610b` |
| SD 裝置 | `/dev/mmcblk0`，`59.5 GiB`，序號 `0x97bc8c07` |
| 寫入命令結果 | `2034237440` 位元組，約 `59.5 MB/s` |
| 完整範圍回讀 | SHA-256 與來源映像相同 |
| bootloader 回讀 | 8 KiB 偏移、`1154976` 位元組逐位元一致 |

第一次開機時 Armbian 把 rootfs 從映像原始大小擴充至 SD 卡可用範圍；因此
開機後不能再用整張卡雜湊與原始映像比較。bootloader、核心與裝置樹沒有在
測試途中更換。

## SPL 與 U-Boot

```text
U-Boot SPL 2026.01_armbian-2026.01-S127a-P1f88-Hc6a9-V3946-Be6d8-R448a
M4ZDDR1_PROFILE0 clk=792 type=8 wl=0 rc=1 rt=0 wt=0
M4ZDDR1_PROFILE1 dx_odt=07070707 dx_dri=0e0e0e0e ca_dri=00000d0d odt_en=aaaaeeee
M4ZDDR1_PROFILE2 tpr6=3a808080 tpr10=402f6663 tpr11=24242422 tpr12=110f1111
M4ZDDR1_FINAL size_mib=4096 ranks=2 width=32 rows=16 cols=10
```

四次 geometry 探測均一次通過，最終結果為 4,096 MiB、x32、2 Rank、
16 Rows、10 Columns。TF-A `v2.12.9` 找到 AXP313 並正常交接 U-Boot；
U-Boot 完成 initrd checksum、DTB、overlay 與核心載入。
