# A1 0845 792 MHz 候選建置與映像證據

## 結論

A1 已從提交 `6e05b3313` 完成標準 U-Boot、TF-A、DEB 與完整 Jammy
工程測試映像。套件、U-Boot 工作樹與映像內 bootloader 逐位元一致；XZ
解壓串流 SHA-256 也與未壓縮 IMG 一致。這證明建置與封裝正確，不代表
0845 已完成斷電冷啟動、Linux 全容量壓力或量產驗收。

## 候選設定

```text
DRAM_CLK=792
DX_ODT=0x07070707
DX_DRI=0x0e0e0e0e
CA_DRI=0x0d0d
ODT_EN=0xaaaaeeee
TPR6=0x3a808080
TPR10=0x402f6663
TPR11=0x25252523
TPR12=0x110f0f10
```

此版本啟用唯讀 `M4ZDDR1` 診斷，停用執行期 `M4ZLAB2` 實驗器。參數來源與
0845 邊界證據見 `M4ZLAB2-hardware-0845-20260819.md`。
