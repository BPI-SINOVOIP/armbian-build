# X2 在三星 S322 的標準啟動 G1 證據

## 結論

三星 `S322` 使用與 1116、S337 相同的 X2 792 MHz 標準映像完成一次完全斷電
冷啟動。SPL 正確從雙 Rank 探測退回單 Rank，最終識別 2,048 MiB、x32、
1 Rank、16 Rows、10 Columns；TF-A、U-Boot、核心、initramfs、rootfs 與
使用者空間全部通過。

另完成 180 秒、1.4 GiB 記憶體與 4 個 CPU worker 的冒煙測試，結束碼為
`0`，沒有 OOM、page fault、panic、Oops、EDAC 或資料毀損訊息。

本結果通過 DDR 與標準啟動 G1，並計入 G2 `1/10`。systemd 因沒有可監控的
網路介面導致 `vnstat.service` 失敗，狀態為 `degraded`；因此本結果不能用來
宣稱 Wi-Fi、Bluetooth 或全部系統服務正常，也不能取代完整 G3、G4。

## DDR 與啟動鏈

```text
M4ZDDR1_PROFILE0 clk=792 type=8 wl=0 rc=1 rt=0 wt=0
M4ZDDR1_PROFILE1 dx_odt=07070707 dx_dri=0e0e0e0e ca_dri=00000d0d odt_en=aaaaeeee
M4ZDDR1_PROFILE2 tpr6=3a808080 tpr10=402f6663 tpr11=24242422 tpr12=110f1111
M4ZDDR1_BEGIN ranks=2 width=32 rows=13 cols=8
M4ZDDR1_STAGE stage=rc result=fail attempts=5
M4ZDDR1_BEGIN ranks=1 width=32 rows=13 cols=8
M4ZDDR1_STAGE stage=rc result=pass attempts=1
M4ZDDR1_FINAL size_mib=2048 ranks=1 width=32 rows=16 cols=10
```

第一次雙 Rank read calibration 失敗五次是容量探測的一部分；程式隨即改用
單 Rank，後續四個 geometry 階段都一次通過。最終結果與三星 16 Gb 單 Rank
料號預期一致，不是 DDR 初始化失敗。

U-Boot 完成 initrd checksum、DTB、overlay 與核心載入。Linux
`6.18.32-current-sunxi64` 回報 `1914268K/2097152K` 可用記憶體。

## MMC 編號核對

initramfs 與 Linux 將 rootfs 顯示為 `/dev/mmcblk2p1`，與 S337 使用的
`/dev/mmcblk0p1` 名稱不同。以下硬體識別證明它仍是同一張測試 SD 卡：

| Linux 裝置 | 控制器 | 名稱 | 類型 | 容量 | 用途 |
| --- | --- | --- | --- | ---: | --- |
| `/dev/mmcblk2` | `4020000.mmc` | `SR64G` | SD | `59.5 GiB` | rootfs `/dev/mmcblk2p1` |
| `/dev/mmcblk1` | `4022000.mmc` | `8GTF4R` | MMC | `7.28 GiB` | 板載 eMMC，未掛載 |

rootfs UUID 為 `79b65bfb-8d06-41a2-950a-8aa06b351317`，與核心命令列及前兩片
測試一致。Linux 裝置編號取決於控制器探測順序，不代表從 eMMC 啟動。

## 短壓力測試

```bash
stress --vm 1 --vm-bytes 1400M --vm-keep --cpu 4 --timeout 180s
```

```text
stress: info: successful run completed in 180s
STRESS_RC=0
```

測試後可用記憶體約 1.8 GiB，swap 使用量為零；核心日誌未命中 OOM、
page fault、panic、Oops、資料毀損、Data Abort 或 EDAC 關鍵字。這是冒煙測試，
尚未涵蓋全可用容量 pattern、溫度角落或記憶體與 MMC 長時間並行。

板上時鐘尚未透過網路校時，UART 中的系統日期為 2026-05-21；本證據以主機
建立目錄與擷取時間 2026-08-13 為準。

## 非 DDR 周邊異常

```text
mmc0: Failed to initialize a non-removable card
Bluetooth: hci1: command 0x0c03 tx timeout
Bluetooth: hci1: BCM: Reset failed (-110)
vnstatd: No interfaces found in database, adding available interfaces...
vnstatd: Nothing to do, exiting.
```

`ip -br link` 只列出 loopback，因此 `vnstat.service` 反覆重啟後失敗，systemd
狀態為 `degraded`。以上未影響 DDR、測試 SD、eMMC 枚舉、rootfs 或記憶體
冒煙測試，故不阻擋 DDR G1；無線周邊必須另行修復並驗證。
