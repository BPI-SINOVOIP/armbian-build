## 使用邊界

這張卡啟動後只執行 M4ZLAB2，不進入 U-Boot proper、TF-A 或 Linux。UART
出現 `M4ZLAB2_READY` 後，主機工具可即時下發完整 DDR profile；每組參數
不需要重新編譯或重新燒錄。

寫入 M4ZLAB2 前曾把完整 OS 除錯映像寫到同一張卡，但該映像不作為本輪
benchmark 輸入。8 KiB 偏移的 M4ZLAB2 SPL 已覆蓋其啟動入口，且實驗器不會
繼續載入卡上的 OS 內容，因此不影響 DDR 掃描。
