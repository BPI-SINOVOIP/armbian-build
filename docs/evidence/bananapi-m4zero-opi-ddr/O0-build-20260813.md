# O0 Orange Pi DDR 基線建置證據

## 實驗定義

O0 使用 upstream Orange Pi Zero 3 的 H618 LPDDR4 profile，頻率固定為
792 MHz。BPI-M4 Zero 只保留板級 DTS／defconfig 必要差異，不加入自製
Rank fallback，也不加入容量探測的 150 us 額外延遲。

本文件記錄可重現建置證據，不代表實機穩定性認證。
