## 修正與阻擋

- AI2N：依原腳本保留 splash／Plymouth 及 UART／tty1 語意，不改原環境或額外加入參數。
- M6：原腳本不依 `bootlogo`／`console` 改變 bootargs；解析器保留這個行為，不自行加入 splash。
- SM10：只允許已核定 K3 SDK 的兩個精確來源路徑及摘要，不放行任意外部檔案。
- R2：十套原環境均引用不存在的 `/boot/dtb/mediatek/mt7623n-bananapi-bpi-r2`。
  既有 F 階段[內部修正候選](bananapi-r2-dtb-path-fix-20260918.md)不替換原清單或算進通過數。
  若需客戶測試，須另外提供修正且固定摘要的來源；內部候選不等於已授權發布。
