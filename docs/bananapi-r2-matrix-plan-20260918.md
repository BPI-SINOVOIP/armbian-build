## 範圍

固定 G 最終索引 SHA-256
`1244f805eb86553e598074320ad1bcda670c74bbba24cd3db322db1b32a683d9`，
僅接受其中 R2 的 Bookworm、Jammy、Noble、Resolute、Trixie，各 CLI／XFCE 共十套。
沿用原核心 `6.6.153-current-mt7623`，不升級核心或引導載荷，不重新編譯。

原 XZ、原硬體資料庫、G 結論與既有候選均不改寫；不操作硬體或覆寫發布目錄。
新候選只在獨立證據目錄建立。所有候選保持內部測試、未實板驗證及未授權對外發布。
F 已有的 Bookworm CLI 候選按完整來源及產物證據核對後重用，不重建相同候選。

## 執行與驗收

| 階段 | 工作 | 驗收 |
| --- | --- | --- |
| I1 | 計畫先推送；逐套核對原來源、解壓摘要、環境、根身分與既有證據 | 十個唯一來源，缺證或差異明示，不以單一樣本外推 |
| I2 | 在既有固定樣本工具上加入受控矩陣契約及可續作記錄 | 保持舊預設行為；未知來源、環境、DTB、越界及產物漂移均拒絕 |
| I3 | 依 OS 處理九個新候選；既有一套核對重用 | 僅替換原環境中的 DTB 路徑且保持長度；原核心、initrd、DTB、腳本不變；唯讀 e2fsck 及正式 XZ 準備通過 |
| I4 | 核對所有候選的來源關係、差異範圍與讀回；完整回歸、文件及紀錄推送 | 十套內部候選全部有證據，原十套仍為阻擋，不混入原 444 筆通過數 |

每套使用固定來源摘要與既有擷取綁定環境，不允許任意字串替換。
ext inode 須為明列權限、單連結的一般檔案，且環境位於已核對資料區塊。
保留同長度註解填補策略；複製時計算原 raw 及新 raw 摘要，另以逆向替換
重算整份原摘要，確認修改區間以外沒有變更。
以新 raw 回讀組件及檔案系統，再壓縮並從最終 XZ 由正式入口重新解析。
壓縮與解析失敗保留嘗試；已完成結果只在來源、契約、工具及產物相符時重用。

本輪不宣告原生引導、實板開機、eMMC、周邊、量產或對外發布通過。
客戶發布仍須另外確認既有引導載荷的再散布權限，不能因路徑修正而解除限制。
H1／H2 的實板配對、備份、首次核定與硬體測試仍需接板後完成。

## 操作入口

在本分支工作目錄使用既有 Python 3.10 環境：

```bash
PY=output/evidence/bpi-sram-supervisor/model-venv/bin/python
$PY -B tools/bpi_lab_r2_matrix.py init \
  --output output/evidence/bpi-r2-matrix-I-20260918/batch-003 \
  --previous-plan output/evidence/bpi-r2-matrix-I-20260918/batch-002/plan.json \
  --previous-plan-sha256 6d590dc8f61f39015e67557e267130af320c7f246a76d60f5833fc5bbca159ef
```

初始化成功會輸出新 `plan.json` 路徑與 SHA-256。以該固定摘要交給 `run` 的
`--plan`、`--plan-sha256` 參數；同一命令可續作，但工具或證據改變會拒絕。
不同工具版本必須另建計畫，使用 `--previous-plan` 與對應摘要核對重用已完成結果。
新計畫只接納有完整收據的候選，不把半成品當成完成，也不覆蓋失敗日誌。

每次最多兩個映像工作，同一 OS 完成才換下一 OS。新候選的 XZ 各用四條執行緒，
保留內部 raw 供完整逆向核對；不是新增對外發布目錄，也不要求上傳 raw。
全部十套完成後才寫 `summary.json`；中斷時以各工作 `receipt.json` 判斷已完成項目。
