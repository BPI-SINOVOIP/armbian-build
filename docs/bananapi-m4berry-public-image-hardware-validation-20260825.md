## 驗證目的

本次以使用者已燒錄的 Banana Pi M4 Berry A1 H618 792 MHz Noble XFCE 映像，
透過 UART 與 SSH 驗證系統穩定性、硬體加速、儲存、網路、無線、音訊及 40-pin
基礎介面，並查明 RTL8821CU 在開機後沒有 Wi-Fi 介面的原因。

本紀錄只適用於這次實際測試的單片 2 GiB 板卡。十個修正版映像的建置端驗證、
跨板卡冷啟動與量產資格必須分開判定。

## RTL8821CU 問題與處理

問題不是核心缺少 RTL8821CU 支援。核心設定已有 `CONFIG_RTW88_8821CU=m`，
模組也含 USB 識別 `0BDA:C820`，但舊 BSP 安裝的
`/etc/modprobe.d/8821cu.conf` 含有：

```text
blacklist rtw88_8821cu
```

該設定原本供舊版外掛 `8821cu` 驅動使用；目前映像沒有這個外掛模組，因此造成
主線模組被禁用且沒有替代驅動。實機處理流程如下：

1. 手動載入 `rtw88_8821cu`，確認模組、韌體及硬體可運作。
2. 將舊黑名單設定改名，使 `modprobe` 不再讀取。
3. 暖重啟，不執行手動載入命令。
4. 確認 `rtw88_8821cu` 自動載入、韌體 `24.11.0` 啟動。
5. 確認可掃描 2412 MHz 與 5260 MHz 基地台。

來源修正提交 `89e304237` 已停止將舊設定複製到 M4 Berry BSP，並新增建置端
回歸檢查，防止主線驅動再次被黑名單停用。

## 判讀限制

- 本次原始燒錄檔的壓縮檔 SHA-256 未在燒錄前保存於實機紀錄，因此只能依系統
  版本與內容確認映像家族，不能把這片 SD 的結果當成十個新檔案逐一通過。
- Wi-Fi 測試現有密碼不足 WPA2 的八字元最低要求，未完成連線、DHCP 或吞吐量。
- 一次上電與一次暖重啟不等於冷啟動矩陣；量產前仍需多片 2 GiB／4 GiB 測試。
- 本次核心最高設定約 1.416 GHz；若需求門檻為 1.5 GHz，現版不符合，須另行驗證 OPP、電壓、散熱與穩定性。
- Cedrus 解碼介面可運作不等於所有播放器、編碼設定及解析度都能即時播放。
- HDMI ALSA 串流成功不等於已確認顯示器喇叭實際發聲。
- 本次沒有對 eMMC 寫入、格式化或安裝系統。
