## T1：原系統與傳輸基礎

證據目錄：`output/evidence/bpi-h618-no-mux/T1-0845-20260916/`。

1. 具名電源查詢核對開啟，串口無其他程序持有；固定入口回應 ABI3。未重刷 SPL1、FIT 或候選槽。
2. 經槽 3 載入既有 A1 配套鏈，正常進入原 SD 的 Armbian `25.2.2`，本次 `uname -r` 實收 `6.6.75-current-sunxi64`，root 登入成功。UART 開機紀錄 SHA-256：`8a269b4607db33b073f06a084a6c32342bda28226bc6c61465211c0c86408957`。
3. 先前新增的 SDIO Wi-Fi overlay 本次確實套用，`wlan0` 出現。使用主機已授權網路設定連線，不把密碼放進命令列、版本庫或 TX 紀錄。
4. 建立本次實驗專用 SSH 金鑰；經 UART 取得板子主機公鑰後固定至獨立 `known_hosts`，保持嚴格主機金鑰驗證。板上只追加受來源限制的專用公鑰，不放寬 SSH 密碼認證或改寫原 sshd 設定。私鑰與完整網路資料只在本機私有證據目錄保存。
5. 主機與板上 `/run` 完成各 64 MiB 的雙向傳輸，來源、板上與回傳摘要皆為 `68819252576a08579ba62aab8a716a37d8b3f9eb6c23451d5082e1cfc01e0997`。上傳約 12.15 秒、下載約 13.71 秒，含連線與程式啟動開銷，不視為網路吞吐極限。沒有向 eMMC 寫入測試檔。
6. 已啟動一小時 `stress-ng` 記憶體／CPU 驗證，使用 1 個 2 GiB VM 工作者、2 個 CPU 工作者、資料驗證及遇錯中止；執行中不記為通過。這是原系統引導基線的檢查，不是獨立救援 initramfs 的完成證據。

唯讀盤點報告 `linux-inventory-001.json` 的 SHA-256 為 `fef436d70d1005bf5a8137e8cd369501251c829ac040095db1c8b70afb068ccc`。雙向傳輸重新核對報告 `network-integrity-recheck-001.json` 的 SHA-256 為 `ba849a2559cfd6fa0374ceefe0537a0bae136f1da4b1266ac9decf459340f5c7`。

## 媒體編號與未完成事項

- SD 容量與 CID 仍符合既有紀錄，根系統位於 SD。
- 啟用 SDIO 後，eMMC 由先前的 `mmcblk1` 變為本次的 `mmcblk2`，容量為 `31289507840` 位元組，控制器為 `4022000.mmc`。先前以舊編號的唯讀查詢失敗保留於盤點，不把那些失敗寫成已完成 eMMC 檢查。新的查詢確認 `type=MMC`、CID 及控制器路徑。
- 未辨識到 eMMC 分割表或常見簽章，但不能據此視為無資料。尚未完整備份、尚未取得本輪可覆寫確認、沒有寫入 eMMC。
- 開機仍有既有顯示 `debugfs` 警告，以及藍牙重設逾時、Wi-Fi 掃描部分頻道錯誤。Wi-Fi 成功連線不代表藍牙或所有頻道通過，不在救援傳輸工作中隱藏或擴大修理無關問題。
- 最新上傳目錄的 EMAC 候選為 `6.18.49` 五發行版各 minimal／XFCE 共十套。先做離線核對；舊 `6.18.48` 與 `6.6.75` 不刪除、不重編。普通 Zero 的結果不能替代未接擴充硬體的 EMAC 功能驗證。

## 工具與失敗紀錄

新增 `tools/bpi_lab_console.py`：借用既有排他串口介面，保留一次接收中尚未消耗的提示尾端，使用隨機、行邊界標記區分命令回顯與真正輸出。RX 日誌限制為新建私有檔，接收緩衝有上限；TX 不記錄。逾時不代表遠端命令已停止，呼叫端須另行確認。

主代理已執行 29 項主控台單元測試並通過；其中涵蓋提示尾端、ANSI 回顯、偽標記、逾時、短寫、日誌安全及上限。這是工具測試，不算 29 項硬體功能驗證。

兩次主機端腳本問題均保留原始證據，未因此重刷或重跑映像：

- `ssh-setup-001.bin`：多行 Python 命令遭主控台單行守門拒絕；改用明確單行編碼後在 `002` 完成公鑰追加，沒有放寬命令守門。
- `network-integrity-001.json`：雙向傳輸已完成，但主機 Python `3.10` 沒有 `hashlib.file_digest`，首次腳本因此沒有標記成功。改採相容串流雜湊，並對已存在的兩份 64 MiB 檔案執行 `sha256sum` 及長度核對，另存重新核對報告；原失敗報告不覆寫，沒有重傳相同資料。
