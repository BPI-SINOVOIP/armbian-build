2. 主機與依賴

依指定提交的 README.md：RAM 至少 8 GB，磁碟約需 50 GB 可用空間。
原生建置主機採 Armbian/Debian 13 Trixie；支援 x86_64、aarch64 或 riscv64。
本指南命令選擇原生建置 PREFER_DOCKER=no，須具備 sudo 或 root 權限及可用網路。
README 另列 Docker 與 WSL2，但本指南沒有驗證這些路徑。
先備妥 Bash、Git、sudo 與 CA 憑證，維持系統及套件來源正常。

完整主機依賴以 lib/functions/host/basic-deps.sh 與 lib/functions/host/prepare-host.sh 為準。
框架會安裝依賴，包括編譯器、make、ccache、bison、flex、dtc、u-boot-tools、Python 及映像工具。
跨架構需要對應交叉編譯器與 QEMU/binfmt；不要把簡短套件清單當成完整依賴。
Mesa 另需同發行版的隔離 arm64 環境及原封裝 debian/control 所列依賴。

50 GB 不是保留十套產物的充分容量保證。
本批十份 .img 合計 40986738688 bytes；十份 .img.xz 合計 8026885916 bytes。
兩者合計 49013624604 bytes，尚未計來源、快取、暫存與 Mesa 建包。
Mesa 配方另列參考資源：6 CPU、8 GiB RAM、約 20 GiB 磁碟、無額外 swap。
建置前另行預留這些空間；框架的 10 GiB 磁碟檢查只是警戒，不代表足夠完成。
依序建置，不在同一工作樹同時啟動多套。

先依各配方取得完整來源、驗證官方簽章鏈與 SHA、安裝依賴，再套用補丁及建包。
配方的關鍵命令為 python3 verify-official-source.py、sha256sum -c、apt-get build-dep、
dpkg-checkbuilddeps、dpkg-buildpackage -b -us -uc -j6；不得跳過其前置步驟。
目前配方只在指定來源候選內核對；未重新下載來源、驗簽或建包。
官方索引缺版、驗簽失敗或依賴無法滿足時停止。官方原補丁僅接受配方核對的既有偏移；BPI 與封裝修改必須零 fuzz、零偏移。
不要混用發行版、停用簽章檢查或改用未修補套件。
回補包不是 Debian、Ubuntu 或 Armbian 官方套件。

將核對完成的同版 arm64 Mesa .deb 與 SHA256SUMS.txt 放入各自的獨立套件目錄。
自建套件須使用自己的實際 SHA；不能複製參考產物 SHA 冒充吻合。
最少須有 libgl1-mesa-dri、libegl-mesa0、libglx-mesa0、libgbm1、libglapi-mesa。
另須覆蓋 rootfs 已安裝的全部 Source=mesa 套件；擴充會拒絕缺包、混版與降版。
不要把其他來源套件或未列入清單的 .deb 放入目錄，也不要將 .ddeb 改名為 .deb。
擴充只選擇所需集合，不是將所有開發與除錯套件裝進映像。
映像內的追溯資料位於 /usr/share/bpi-m4zeroemac-mesa/。

Trixie 由板型選用官方 trixie-backports Mesa，要求版本至少 25.2.0。
本批發布說明記錄為 26.1.6，但建置規則未精確釘選該版。
Noble、Resolute 不走本地 Mesa 安裝分支；套件隨其發行版來源解算。
因此十套都不能宣稱已具備完整固定套件快照。

下列路徑是使用者自己的套件目錄範例；先完成對應配方，再按實際位置調整：

    BOOKWORM_MESA_DIR="$HOME/mesa-opt3/bookworm/packages"
    JAMMY_MESA_DIR="$HOME/mesa-opt3/jammy/packages"

每個套件目錄只放本發行版已核對的 Mesa .deb，以相對檔名建立清單：

    (cd "$BOOKWORM_MESA_DIR" && sha256sum -- *.deb > SHA256SUMS.txt)
    (cd "$JAMMY_MESA_DIR" && sha256sum -- *.deb > SHA256SUMS.txt)

    test -f "$BOOKWORM_MESA_DIR/SHA256SUMS.txt"
    test -f "$JAMMY_MESA_DIR/SHA256SUMS.txt"
    (cd "$BOOKWORM_MESA_DIR" && sha256sum -c SHA256SUMS.txt)
    (cd "$JAMMY_MESA_DIR" && sha256sum -c SHA256SUMS.txt)

4. 十組映像建置命令

以下在核定來源根目錄、同一 Bash 工作階段執行。每組成功後才執行下一組。
命令依十套成功紀錄整理；Jammy 使用第二次成功紀錄，不採第一次 BSP 衝突失敗紀錄。
相對原紀錄，移除 sudo -n 與 DONT_BUILD_ARTIFACTS=uboot，讓全新環境能取得或建置 U-Boot。
Mesa 路徑改成使用者目錄；Trixie 額外明列 CARD_DEVICE=，禁止指定直接寫入裝置。
其餘列出的參數保留成功紀錄值。這些整理後的命令尚未在乾淨來源重跑。
未設定 ENABLE_EXTENSIONS=bsp-sysctl-coexist 是刻意且必要的差異。
minimal 必須是 BUILD_MINIMAL=yes；不能以一般 CLI 版替代。
XFCE 必須是 BUILD_DESKTOP=yes、BUILD_MINIMAL=no、DESKTOP_ENVIRONMENT=xfce、DESKTOP_TIER=mid。

5. 輸出、壓縮與 SHA-256

輸出目錄：output/images/bananapim4zeroemac/optimized3-20261010/
COMPRESS_OUTPUTIMAGE=sha 會保留 .img，並產生 .img.sha 與映像說明 .img.txt。
本批採先產生 raw、再壓縮的流程。下列是使用者重建產物的後處理命令。
須先完成十組建置；目錄不可混入其他同名版本，且不得已有同名 .xz 或 SHA256SUMS.txt。
下列命令保留 .img；缺檔、SHA 不符或壓縮失敗即停止。
自己產生的 SHA256SUMS.txt 只識別自己的重建產物，不是原發布檔案的認證。

    set -euo pipefail
    cd output/images/bananapim4zeroemac/optimized3-20261010
    test ! -e SHA256SUMS.txt
    for release in bookworm trixie jammy noble resolute; do
      for variant in minimal xfce_desktop; do
        img="Armbian-unofficial_26.11.0-trunk-opt3_Bananapim4zeroemac_${release}_current_6.18.55_${variant}.img"
        test -f "$img"
        test ! -e "$img.xz"
        test -f "$img.sha"
        sha256sum -c "$img.sha"
        xz -T2 -6 --keep "$img"
        xz -t "$img.xz"
        sha256sum "$img.xz" > "$img.xz.sha"
      done
    done
    cat Armbian-unofficial_26.11.0-trunk-opt3_Bananapim4zeroemac_*_current_6.18.55_*.img.xz.sha > SHA256SUMS.txt
    test "$(wc -l < SHA256SUMS.txt)" -eq 10
    sha256sum -c SHA256SUMS.txt
