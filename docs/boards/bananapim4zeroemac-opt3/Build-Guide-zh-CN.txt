2. 主机与依赖

依据指定提交的 README.md：RAM 至少 8 GB，磁盘约需 50 GB 可用空间。
原生构建主机采用 Armbian/Debian 13 Trixie；支持 x86_64、aarch64 或 riscv64。
本指南命令选择原生构建 PREFER_DOCKER=no，须具备 sudo 或 root 权限及可用网络。
README 另列 Docker 与 WSL2，但本指南没有验证这些路径。
先备妥 Bash、Git、sudo 与 CA 证书，维持系统及软件包源正常。

完整主机依赖以 lib/functions/host/basic-deps.sh 与 lib/functions/host/prepare-host.sh 为准。
框架会安装依赖，包括编译器、make、ccache、bison、flex、dtc、u-boot-tools、Python 及镜像工具。
跨架构需要对应交叉编译器与 QEMU/binfmt；不要把简短软件包清单当成完整依赖。
Mesa 另需同发行版的隔离 arm64 环境及原封装 debian/control 所列依赖。

50 GB 不是保留十套产物的充分容量保证。
本批十份 .img 合计 40986738688 bytes；十份 .img.xz 合计 8026885916 bytes。
两者合计 49013624604 bytes，尚未计来源、缓存、临时文件与 Mesa 构建。
Mesa 配方另列参考资源：6 CPU、8 GiB RAM、约 20 GiB 磁盘、无额外 swap。
构建前另行预留这些空间；框架的 10 GiB 磁盘检查只是警戒，不代表足够完成。
依次构建，不在同一工作树同时启动多套。

不要混用发行版、停用签名检查或改用未修补软件包。
回补软件包不是 Debian、Ubuntu 或 Armbian 官方软件包。

将核对完成的同版 arm64 Mesa .deb 与 SHA256SUMS.txt 放入各自的独立软件包目录。
自建软件包须使用自己的实际 SHA；不能复制参考产物 SHA 冒充吻合。
最少须有 libgl1-mesa-dri、libegl-mesa0、libglx-mesa0、libgbm1、libglapi-mesa。

4. 十组镜像构建命令

以下在核定来源根目录、同一 Bash 会话执行。每组成功后才执行下一组。
命令依据十套成功记录整理；Jammy 使用第二次成功记录，不采纳第一次 BSP 冲突失败记录。
相对原记录，移除 sudo -n 与 DONT_BUILD_ARTIFACTS=uboot，让全新环境能获取或构建 U-Boot。
Mesa 路径改成用户目录；Trixie 额外明列 CARD_DEVICE=，禁止指定直接写入设备。
其余列出的参数保留成功记录值。这些整理后的命令尚未在干净来源重跑。
未设置 ENABLE_EXTENSIONS=bsp-sysctl-coexist 是刻意且必要的差异。
minimal 必须是 BUILD_MINIMAL=yes；不能以一般 CLI 版替代。
XFCE 必须是 BUILD_DESKTOP=yes、BUILD_MINIMAL=no、DESKTOP_ENVIRONMENT=xfce、DESKTOP_TIER=mid。

5. 输出、压缩与 SHA-256

输出目录：output/images/bananapim4zeroemac/optimized3-20261010/
COMPRESS_OUTPUTIMAGE=sha 会保留 .img，并产生 .img.sha 与镜像说明 .img.txt。
本批采用先产生 raw、再压缩的流程。下列是用户重建产物的后处理命令。
须先完成十组构建；目录不可混入其他同名版本，且不得已有同名 .xz 或 SHA256SUMS.txt。
下列命令保留 .img；缺文件、SHA 不符或压缩失败即停止。
自己产生的 SHA256SUMS.txt 只识别自己的重建产物，不是原发布文件的认证。

    set -euo pipefail
    cd output/images/bananapim4zeroemac/optimized3-20261010
    test ! -e SHA256SUMS.txt
    for release in bookworm trixie jammy noble resolute; do
      for variant in minimal xfce_desktop; do
        img="Armbian-unofficial_26.11.0-trunk-opt3_Bananapim4zeroemac_${release}_current_6.18.55_${variant}.img"
        test -f "$img"
        test ! -e "$img.xz"
        test -f "$img.sha"
        sha256sum -c "$img.sha"
        xz -T2 -6 --keep "$img"
        xz -t "$img.xz"
        sha256sum "$img.xz" > "$img.xz.sha"
      done
    done
    cat Armbian-unofficial_26.11.0-trunk-opt3_Bananapim4zeroemac_*_current_6.18.55_*.img.xz.sha > SHA256SUMS.txt
    test "$(wc -l < SHA256SUMS.txt)" -eq 10
    sha256sum -c SHA256SUMS.txt
